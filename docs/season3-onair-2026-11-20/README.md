## 1. 11/18 밸런스 패치 관련

- 서포터 간 격차 커진 것 인정, 클래스 간 격차는 줄일 예정
- 2부에서 특성 6종 → 4종(치명·특화·신속·기량, img/22), 특화계수 통합
- 바드 공깎은 파티 방식으로 변경 예정
- 밸런스 기준: 모든 보스 합산 → 최신 레이드 기준. 신규 레이드 전에 선행 밸패

## 2. 성장 체계 (img/02, img/03)

- 전투력이 대표 성장 요소. 보상도 전투력 기준, 입장 조건 = 전투력 + 아이템 레벨
- 각인: 클래스별 유효 각인은 같은 점수로 맞춤
- 서포터도 딜러와 동일 기준 적용. 보주·보석 등 과하게 반영되는 요소 조정

| 구분 | 성격 | 요소 |
|---|---|---|
| 단기 | 응축된 성장의 재미, 비용 대비 높은 성장 효율 | 장비 파밍, 장비 연마, 장비 옵션 변환 |
| 중기 | 꾸준히 쌓아가는 성장, 1년 주기로 확장 및 완화 | 마력 주입: 위상, 각인 슬롯 업그레이드, 재련 |
| 장기 | 오랜 시간과 비용 소요, 투자한 가치 오래 유지 | 마력 주입: 옵션, 보석 |

- 단기: 선발대 기준 3~4개월이면 끝. 파밍 후 교체, 약 1년 사용
- 중기: 1년 기준 상위 구간 열리고 하위 구간은 쉬워짐. 운 없을 때 안전장치
- 장기: 보석. 주기적 완화 없이 상한만 조금씩 확장

## 3. 장비 슬롯 (img/05, img/11)

- 왼쪽(방어구) 라인에 **허리띠** 신규, 오른쪽(장신구) 라인에 **인장·성물** 신규
- 교차 성장: 왼쪽(방어구·무기·완갑)은 여름 업데이트마다, 오른쪽(장신구·인장·성물)은 겨울 업데이트마다 추가·확장
- 무기·완갑·인장·성물 = 특수슬롯(비용↑ 성능↑). 팔찌는 특수슬롯 쪽으로 이관

| 투구 | 투구 | 목걸이 |

## 4. 단기: 장비 파밍 / 연마 / 옵션 변환 (img/06)

- 레이드 메인, 카던·가토에서도 드랍. 일반~고대 등급, 성장 수준 높을수록 고등급 확률↑
- 연마: 같은 부위 같은 장비를 재료로 **100% 연마**. 부위당 5번, 회당 아이템 레벨 +5
- UI 예시(img/06): 운명의 한손검 4단계(1820.00) → 5단계(1825.00), 연마 비용 10,000골드, 재료 장비 1개
  - 옵션 예: 힘/민첩/지능 +15600, 최대 생명력 +500, 극대화 +75, 무력화 피해 +0.33%
  - 효과 변환: 재료 54/1, 변환 비용 500골드
- 옵션 변환: 고대 전용. 연마할 때마다 옵션 한 줄 개방. 최고값 정해져 있고 천장 있음. '번뜩임' 발동 시 최고값만
- 상단 탭(img/06~09): 연마 / 재련 / 마력 주입 / 아크 그리드 / 각인 / 원정대 보석

## 5. 중기: 슬롯 재련 (img/07)

- 장비가 아닌 **슬롯**에 재련 → 장비 바꿔도 유지. 성능만 오르고 레벨은 안 오름
- 단계 간 격차: 21강 이상 3%, 그 아래는 줄어들어 15강 이하 약 2%
- 파편·돌파석·특수재련 **삭제**. 기존 재료는 2부 재료 토큰으로 교환(직전 몇 주 시장가치 기준, 거래 타입 유지). 캐릭귀속→원정대귀속 구상 중
- 실패 마일리지(장인의 기운): 기존 0.5%→10회 실패 후 1% 방식을 **처음부터 1%**로
- 25강 찍어야 다음 단계. 상위 구간 열린 뒤 하위 구간 난이도 하향
- UI 예시(img/07): 투구 슬롯 11→12단계, 장인의 기운 6.97%, **재련 성공률 5.00%**
  - 보조 재료: 위대한 바늘 30/20
  - 재료 2종(파란 결정 4714/118, 주황 결정 1019/7)
  - 재련 비용 22,567(실링 아이콘) + 1,565골드, "슬롯 재련 3회" 버튼 있음
  - 예시 캐릭 슬롯 단계: 무기 12, 완갑 13, 투구 11, 견갑 11, 상의 12, 허리띠 12, 하의 12, 장갑 12

## 6. 중기~장기: 마력 주입 (img/08)

- 옵션 뽑기 + 옵션 성장을 하나로. 재료+골드로 주입 시 옵션 3개 등장, 마음에 드는 것 저장. 성능은 전투력으로 표시
- 상단 '마력 포화도' 게이지로 위상 상승, 총 7위상, 1년에 한 번 확장. 위상 오르면 저장 옵션 수치 증가. 재굴림 재료 매우 희귀
- UI 예시(img/08): 성물 슬롯 전투력 7,571.04 → 7,602.55, 제2위상 포화도 1290/10000
  - 보구 마력 제어기 3/1, 변성 비용 750골드, 마력 변성 시도 3/3
  - 옵션 예: 최대 마나 +25(최상급), 스킬 위력 +0.24%(중급), 기본 공격력 +1850(상급)
  - 연마 비용 3,000골드, 재료 220/10
  - 대상 슬롯: 보구(성물·인장), 장신구(목걸이·귀걸이×2·반지×2·팔찌)

## 7. 중기: 각인 슬롯 업그레이드 (img/09)
