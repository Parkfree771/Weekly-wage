# 광고(구글 애드센스) 구조

## 파일
- `adConfig.ts` — 토글(`AD_PREVIEW`)·애드센스 클라이언트·슬롯 ID·자리별 칸 크기(`AD_SIZES`) 한 곳 모음.
- `AdPlaceholder.tsx` — "여기 광고 들어감" 미리보기 박스(자리/크기).
- `AdSenseUnit.tsx` — 애드센스 광고 단위. CSS 로 정한 칸에 반응형 단위를 띄운다(마운트 후 ins 1개당 push 1번).
- `AdBanner.tsx` — 모바일 인-콘텐츠. 페이지 안에 직접 배치.
- `DesktopBannerAd.tsx` — 데스크톱 본문 가로 띠.
- `AdLayout.tsx` — 데스크톱 좌우 레일을 레이아웃 레벨에서 배치.
- 패키지 상세 좌측 사각은 `components/package/SideSquareAd.tsx`, 갤러리 카드 칸·페이저 아래는 `PackageGalleryClient.tsx`.

## 슬롯(콘솔 단위 4개)
| 키 | 자리 | 칸 |
|---|---|---|
| mobileInContent | 모바일 본문 전 자리 | 폭 100%(최대 336) × 250 |
| desktopHorizontal | PC 가로 띠(목표 아래·결과 아래 등) | 폭 100%(최대 970) × 90 |
| desktopSquare | 패키지 상세 좌측 / 갤러리 카드 칸·페이저 아래 | 250×250 / 336×280 |
| rail | PC 좌우 레일 | 160×600 |

애드센스는 같은 단위를 한 페이지에 여러 번 넣어도 전부 채운다 — 자리별 단위 분리는 리포트 구분용.

## 광고 위치(기기별)
- 데스크톱: 좌우 레일(160×600) + 본문 가로 띠. 레일은 `RAIL_PAGES` + 넓은 화면일 때만.
  - **레일은 스크롤을 따라오지 않는다.** 애드센스는 따라오는 광고를 화면에 하나만, 좌우 대칭 없이,
    폭 300 이하·데스크톱에서만 허용한다. 양쪽 sticky 로 되돌리지 말 것.
- 모바일: 하단 앵커는 코드로 두지 않는다(애드센스 콘솔 자동광고 앵커로만 가능).
  본문 인-콘텐츠(AdBanner)만 사용, **앱(AdMob) 배치를 그대로 미러링**:
  - `/`(메인): 시세 차트·통계 아래
  - `/mypage`: 캐릭터 카드 2개마다 1개(최대 4), 1개뿐이면 그 아래
  - `/refining`·`/wangap`: 시뮬 본문 아래 (상단 배치의 오클릭 회피)
  - `/package` 갤러리: 카드 2개마다 1개, 마지막 뒤 제외 + 페이저 아래 (페이지당 카드 6개, 모바일만 — 데스크톱은 카드 사이 광고 없음)
  - 그 외 페이지: 본문 아래

## zoom 역보정
데스크톱 body zoom 0.85(≥1024px), 모바일 viewport initialScale 0.8 — 그대로 두면 광고가 축소 렌더된다.
광고 컨테이너마다 역배율을 건다: 모바일 `MOBILE_AD_ZOOM_COMPENSATE`(1.25), 데스크톱 `.slot`·
`.desktopAdSlot`·`.sideAdSlot`·레일 래퍼(1.1765). 새 자리를 만들 때도 같은 보정을 걸 것.

## 페이지 이동 시 새 광고 (SPA 대응)
App Router 는 라우팅 시 레이아웃이 안 죽음 → 광고마다 `key={pathname}`(또는 페이지 번호)로 새 ins 를 만들어 새 광고를 받음.
**쿼리스트링/타이머 새로고침은 정책 위반이라 금지.**

## 정책 체크
- 버튼·시뮬 연타 영역 바로 옆 금지(구글 권장 150px 이상), 광고를 메뉴·링크처럼 꾸미기·유도 문구 금지.
- 광고가 콘텐츠보다 많으면 안 됨. 모바일은 광고가 본문 높이의 30% 를 넘지 않게(Better Ads).
- 본인/지인 클릭 금지.
